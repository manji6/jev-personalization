# 設定と上限

## 実行時設定

| 名前                        | 意味                                                |
| --------------------------- | --------------------------------------------------- |
| AUTH_MODE                   | passkeyで新管理画面を使用                           |
| AUTH_ORIGIN                 | 固定された管理画面Origin。HTTPS、末尾スラッシュなし |
| AUTH_SECRET                 | 環境ごとの署名Secret。32文字以上                    |
| ADMIN_TOKEN                 | 初回Superuser登録用。32文字以上                     |
| JEV_API_KEY                 | Jevの実判定用キー                                   |
| JEV_MODEL                   | 初回設定に使うモデル名                              |
| DAILY_REQUEST_BUDGET        | 初回設定に使うUTC日単位の実行上限                   |
| MAX_CONCURRENT              | 初回設定に使う同時実行数                            |
| DEPLOYMENT_TIER             | Previewだけpreviewを指定                            |
| PREVIEW_MODEL_MODE          | Previewのstubでテスト値を使用                       |
| PREVIEW_ACCESS_DOMAIN / AUD | Accessの信頼する発行元と対象アプリ                  |

モデルと予算は初回登録時に管理DBへ引き継ぎます。以後の設定元はSuperuserの「JevSense管理」です。環境変数だけを書き換えてDBの値を上書きする運用ではありません。

## 管理画面の主要設定

| 設定             | 範囲                              |
| ---------------- | --------------------------------- |
| サイトのOrigin   | 最大10件                          |
| サイト           | 最大100                           |
| 公開設定の施策   | サイトあたり最大5                 |
| 質問             | 施策あたり最大5、サイト合計最大10 |
| 案内内容・各条件 | 各400文字以内                     |
| 判定閾値         | 0.5〜0.99。厳密に上回る場合       |
| 表示回数         | 1〜10                             |
| 優先順位         | 0〜100                            |
| 有効閲覧時間     | 1000〜300000ミリ秒                |
| 必要な有効閲覧数 | 1〜10                             |
| 保存下書き       | サイトあたり最大20                |
| パスキー         | ユーザーあたり最大10              |

## 入力・通信の上限

要求本文は64KiB。有効な閲覧履歴は最大50件、任意イベントは最大30件、確定状態は最大20項目です。上限内でもページ情報の長さによって本文サイズの上限に達する場合があります。

許可された名前・経路・型だけを使い、未知の値や不正な確率は表示対象としない設計です。

## 期限

| 対象                       | 期限・扱い             |
| -------------------------- | ---------------------- |
| 管理セッション             | 無操作30分、絶対12時間 |
| 重要操作の再認証           | 5分以内                |
| 招待リンク                 | 24時間、1回限り        |
| Superuserの復旧リンク      | 5分、1回限り           |
| 認証challenge              | 5分、1回限り           |
| 実ページ確認チケット       | 5分、1回限り           |
| 独自コードの確認用取得権限 | 30秒、1回限り          |
| 診断認可                   | 最長15分               |

## APIの大まかな役割

公開SDKは`/v1/sites/:siteId`、`/v1/decision`等を使います。管理者のログインは`/auth/*`、サイト別管理は`/admin/api/v2/*`です。

管理Cookieや管理トークンをSDKへ配らないでください。実際のスキーマと競合制御は[詳細設計](https://github.com/manji6/jev-personalization/blob/feature/admin-v2-implementation/docs/admin-v2-design.md)を参照してください。
