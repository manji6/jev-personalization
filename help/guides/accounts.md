# ログイン・アカウント・招待

## ログインする

管理画面でメールを入力し、パスキーでログインします。端末の顔・指紋・PIN、または対応するセキュリティキーで本人確認します。メールアドレスはログインIDです。

Cloudflare Accessで保護した確認環境では、先にAccessのメールコード等で入場します。これはJevSenseのパスキーとは別の入口です。

## 初めて使う

**環境の最初の管理者**は、表示名・メール・初回ADMIN_TOKENでパスキーを登録します。最初のユーザーはSuperuserです。Accessに連携したPreviewでは、認証済みメールに固定して登録し、共有トークンは入力しません。

**招待された方**は、管理者から受け取ったリンクを開いて表示名とパスキーを登録します。リンクは24時間・1回限りです。期限切れなら管理者に再発行を依頼します。

既存アカウントがある場合は、そのパスキーでログインして招待を受けます。サイトごとにアカウントやパスキーを作り直す必要はありません。

## 表示名とパスキーを管理する

左下のアカウントから表示名を変更できます。全サイトで共通の名前であり、ログインIDや権限は変わりません。メールアドレス変更は今回の機能に含みません。

![アカウント設定](/images/account.png)

「別のパスキーを追加」で予備の端末やキーも登録します。最後の1つは削除できません。重要な操作では5分以内のパスキー本人確認を求めます。

## 権限とサイトの切り替え

| 権限         | 主な範囲                                               |
| ------------ | ------------------------------------------------------ |
| Superuser    | 全サイト・全ユーザー・環境設定                         |
| サイト管理者 | 所属サイトの施策・設定・デザイン・メンバー・独自コード |
| 編集者       | 所属サイトの標準施策の作成・配信・確認                 |
| 閲覧者       | 所属サイトの参照                                       |

複数サイトに所属している場合、上部ヘッダーで切り替えます。サイトごとに権限が異なることもあります。表示されないサイトは、管理者へ所属を確認してください。

## メンバーを招待する

サイト管理者は「メンバー」からメールと権限を指定し、招待リンクを本人へ共有します。メールは自動送信しません。メールの所有確認が自動で完了したという意味でもありません。

同じメールへの再発行では、以前のリンクを無効にします。不要な招待は取り消します。登録済みメンバーの権限変更は、招待のやり直しではなくメンバー一覧から行います。

## 端末を失った場合

まず別の登録済みパスキーを試します。使えない場合は「パスキーが使えない場合」から、事前に保存した復旧コードで新しいパスキーを登録します。

復旧コードは8個、発行時だけ表示します。再発行すると旧コードは無効です。復旧完了時には旧パスキー・全ログイン・残りのコードも無効になるので、新しいコードを発行してください。

コードもない場合は、Superuserへ本人確認と5分・1回限りの復旧リンクの発行を依頼します。最後の有効なSuperuserは無効化・降格できません。

## ログインの期限

無操作30分、ログインから12時間で再ログインが必要です。「他のログインをすべて終了」では、このブラウザ以外のログインを終了できます。ユーザー停止・全体権限変更・復旧でもセッションを無効にします。
