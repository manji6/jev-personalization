# プレビューと動作確認

## 3つの確認方法

| 方法                     | 目的                             |
| ------------------------ | -------------------------------- |
| 管理画面内の表示イメージ | 入力中の見た目を確認する         |
| 施策一覧のプレビュー     | 実ページへ1回だけ強制表示する    |
| 動作確認の診断パネル     | 通常の計測・送信・判断を観測する |

システムの更新用Cloudflare Previewは、[別の環境を確認する機能](../getting-started/preview-production)です。

## 実ページへ確認表示する

1. 内容を下書き保存する。
2. 施策一覧の「プレビュー」を押す。
3. 確認したいページURLを入力する。
4. 「ページを開いて確認」を押し、管理画面も開いたままにする。

保存済み下書きを優先し、なければ保存済みの配信内容を使います。未保存の編集は含みません。停止中や通常配信前の施策も確認できます。

## URLの条件

サイトの登録Origin、収集許可/除外経路、施策の表示対象に一致する必要があります。たとえば完全一致`/ja/`の施策を、`/ja/products/a`で確認することはできません。

対象ページには最新版のSDKが必要です。CMPによりSDK自体が読み込まれない場合は起動できません。サイトのHTMLを勝手に書き換えたり、タグを自動注入する仕組みではありません。

## 1回限りの仕組み

確認チケットは5分・1回限りです。管理画面から今回開いたタブへ渡し、指定施策を表示します。チケットそのものをページURLやWeb Storageへ保存しません。

確認中は通常の計測・自動判断を休止します。Jevを呼ばず、通常の履歴、表示回数、閉じた状態を更新しません。ページ上にも確認表示であることを示します。

閉じる・ページ移動で終了します。同じURLのコピーや再読み込みで強制表示は引き継ぎません。再読み込み後に条件を満たして通常配信される場合は、別の動作です。

## 表示できなかった場合

期限切れ、設定変更、権限変更、CSP、画像、ポップアップ制限、COOP等を確認します。チケットの引換後に描画失敗しても使用済みになるため、新しいプレビューを起動してください。

独自JavaScriptの確認は管理者以上に限ります。作者はpreview modeで独自の計測や更新を抑止してください。

## 配信の最終確認

強制表示が成功しても、対象者判定が正しいと検証したことにはなりません。通常配信では、同意・有効閲覧・確定条件・Jevの判定値・閾値・表示制約を通ります。[診断パネル](./debugging)で通常の流れも確認します。
