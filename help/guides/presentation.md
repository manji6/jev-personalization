# 表示形式と独自JavaScript

## 標準の3形式

| 形式                 | 用途                                     |
| -------------------- | ---------------------------------------- |
| モーダル             | 中央にまとまった案内を表示する           |
| フローティングバナー | 画面の右下または左下から控えめに案内する |
| 通知バー             | 上部または下部に短いお知らせを表示する   |

表示タイトル・本文は文字列として扱います。標準形式へ任意のHTMLを貼る機能ではありません。基本デザインは[サイト設定](./sites)で共有します。

## リンクと画像

リンク先と画像はHTTPS URLです。リンク先を設定した場合はボタンの文言も入力します。

画像だけの表示には、画像URLと画像内容を説明する代替テキストが必要です。画像が読み込めない画像のみオファーを、表示成功として数えません。画像アップロード機能はありません。

## 管理画面内のプレビュー

保存前に小さな枠で見た目を確認できます。実際の画面幅、サイトのCSP、周囲の要素まで再現するものではないため、配信前には[実ページプレビュー](./testing)も使います。

## 独自JavaScript

サイト管理者がサイト設定で許可すると使えます。登録・変更・確認は管理者またはSuperuserに限ります。

```js
export function render(context) {
  const element = context.mount.ownerDocument.createElement("div");
  element.textContent = context.variables.message || context.content.title;
  context.mount.append(element);
  context.reportShown();
  return () => element.remove();
}
```

文字列の入力例です。

```json
{
  "message": "あなたにおすすめのご案内です"
}
```

| context       | 内容                               |
| ------------- | ---------------------------------- |
| content       | 保存済みのタイトル・本文・リンク等 |
| variables     | 管理画面で設定した文字列           |
| mount         | 描画先のShadowRoot                 |
| signal        | 終了時に中断されるAbortSignal      |
| close()       | オファーを閉じる                   |
| reportShown() | 実際に表示できたことを報告する     |
| mode          | 通常はdelivery、確認表示はpreview  |

`export function render(context)`を1つ記述します。後片付けが必要なら関数を返します。実際に描画できたときだけ`reportShown()`を呼びます。

独自の計測や更新処理は、`context.mode === 'preview'`のとき実行しないよう作者が対応してください。SDKは通常の表示回数を増やしませんが、独自コードの副作用をすべて取り消すものではありません。

::: warning コードはサイトと同じ権限で動きます
サンドボックスではありません。信頼できるコードだけを登録し、APIキー・トークン・個人情報を埋め込まないでください。コードとvariablesはブラウザへ配信する公開情報です。管理画面内では独自コードを実行しません。
:::

サイト側のCSPでは、SDKの配信元、APIへの接続、画像、必要な独自モジュールの読み込みを許可します。サイト全体のCSPを無条件で緩めず、必要な配信先だけを設定してください。
